📝 티스토리 마크다운 포스터

마크다운을 티스토리 맞춤형 리치 서식으로 즉시 변환하여 표, 코드 구문 강조를 그대로 적용합니다.

💡 아이폰 / 모바일 작성 꿀팁:
  1. 하단의 [📋 서식 복사] 버튼을 터치하여 클립보드에 담습니다.
  2. [🚀 글쓰기 열기]를 눌러 관리자 페이지로 이동합니다.
  3. 사파리 주소창의 `가(AA)` 버튼 → [데스크탑 웹사이트 요청]을 누르면 PC와 동일한 웹 에디터가 열립니다.
  4. 본문에 [붙여넣기]를 하면 표와 다크 테마 코드가 완벽하게 적용됩니다!
✍️ 마크다운 본문 작성
👁️ 티스토리 렌더링 미리보기
마크다운을 입력하면 실시간으로 미리보기가 생성됩니다.
✅ 서식이 복사되었습니다!
티스토리 관리자 글쓰기 창에서 [붙여넣기]를 실행하세요.
